# Smart Curtains Feature

## What this adds
- Auto-detect room direction based on time
- Smart suggestion (open/close curtains)
- Smooth animation when toggling

## How to use

### 1. Add CSS
Include smartCurtains.css in your project.

### 2. Add JS
Include smartCurtains.js in your HTML.

### 3. Add to HTML
Add this somewhere in your UI:

<div id="suggestion"></div>
<button onclick="toggleCurtains()">Toggle Curtains</button>

Make sure your curtain element has class:

<div class="curtain open"></div>

## Done
